## 🚀 Featured Projects

### DealHunterAI — Autonomous Deal Discovery

An autonomous multi-agent AI system that hunts for online deals in real time.

- Uses a custom fine-tuned LLM deployed as a serverless API.
- Includes a RAG pipeline backed by **800,000 product embeddings**.
- Combines a frontier model with an autonomous planning agent.
- Scans, evaluates, and surfaces the best bargains automatically.

### Agentic RAG

An advanced RAG system where the agent chooses which tools to call and in what order.

**Key features:**

- Agentic retrieval
- Semantic vector search with embeddings and ChromaDB
- Keyword search for exact terms and names
- Semantic chunking using an LLM
- LLM-generated chunk summaries
- Reranking of retrieved chunks
- Self-evaluation for accuracy, relevance, and completeness
- Gradio-based chat UI

### Autonomous Trading AI Agents

A multi-agent trading simulation powered by **OpenAI Agents** and **MCP**.

- Agents research, trade, and rebalance autonomously.
- Each agent follows a different trading behavior or strategy.
- Demonstrates tool use, autonomous decision-making, and multi-agent coordination.

### RAG Evaluator

An evaluation framework for RAG pipelines that measures both retrieval quality and answer accuracy.

- Designed to make RAG systems measurable instead of relying on guessing.
- Focuses on retrieval evaluation and answer-level assessment.
- Useful for testing whether a RAG pipeline is actually improving.
